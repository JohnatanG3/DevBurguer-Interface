
# 🎨 DevBurguer Interface

Frontend da aplicação **DevBurguer**, com área pública para clientes e painel administrativo para gerenciamento interno.

> Backend da aplicação: [DevBurguer API](https://github.com/JohnatanG3/DevBurguer-API)

---

## 🚀 Tecnologias utilizadas

- React
- Vite
- React Router DOM
- Styled Components
- Axios
- React Hook Form
- Yup
- Stripe
- Material UI

---

## 🔐 Funcionalidades

### Área do usuário

- Cadastro e login
- Página inicial com destaques
- Cardápio com categorias
- Carrinho de compras
- Checkout
- Pagamento com Stripe

### Área administrativa

- Gerenciamento de pedidos
- Cadastro de produtos
- Edição de produtos
- Listagem de produtos

## ▶️ Como executar o projeto

```bash
pnpm install
Crie o arquivo .env com base no .env.example
Depois execute:
pnpm dev
```
---

### Usuário

- /carrinho
- /checkout

### Administrador
